# Borge Labs

An independent Norwegian product studio building AI-assisted tools where
sources, privacy and correctness matter.

## Products

- [Politikkradar](https://politikkradar.no) makes Norwegian politics easier to
  follow, with visible sources behind every summary.
- [Ordrett](https://ordrett.app) is Norwegian-first speech-to-text for meetings,
  interviews and lectures, on iOS and Android.
- [Kontert](https://kontert.no) is self-hosted bookkeeping for Norwegian
  associations and small businesses, now in early access.

## Archived research

- [AI Dev Team](https://github.com/Borge-Labs/ai-dev-team): a supervised
  coding-agent runtime with published benchmarks, negative results included.
- [AI Team](https://github.com/Borge-Labs/ai-team): a Slack-native framework
  for configurable AI teammates.

Both are read-only and kept public for anyone who wants to learn from or fork
them.
